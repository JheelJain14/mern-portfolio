# Curriculum Vitae (CV) / Resume Directory

This directory stores the downloadable resume files for Jheel Jain's Portfolio.

## Required Files:
1. `Jheel_Jain_Resume.pdf` - PDF version of your resume.
2. `Jheel_Jain_Resume.docx` - Word (.docx) version of your resume.

### Instructions:
Simply replace the placeholder files in this folder (`client/public/cv/`) with your actual resume files, keeping the exact filenames:
- `client/public/cv/Jheel_Jain_Resume.pdf`
- `client/public/cv/Jheel_Jain_Resume.docx`

The website's "Download CV" buttons in the navigation and hero section automatically link to these files:
- Direct PDF Download: `/cv/Jheel_Jain_Resume.pdf`
- Direct DOCX Download: `/cv/Jheel_Jain_Resume.docx`
- Backend API Endpoint: `/api/cv/download/pdf` & `/api/cv/download/docx`
